# M2E 测试执行指南（供测试者 AI/Agent 使用）

## 核心职责

人类测试者默认完全不懂代码。你承担全部技术判断；每次只让人类执行**一个**动作。

人类只负责：

- 按你的指示复制、粘贴命令；
- 保持你要求保留的终端窗口打开；
- 原样转发结果。

不要要求人类分析、修改、排错或选择技术方案。

仓库地址：`https://github.com/wudy29/ai-collab-room`

## 1. 获取或更新仓库

先判断仓库是否存在。

- 不存在：依次让人类执行 `git clone https://github.com/wudy29/ai-collab-room`、进入仓库目录、执行 `npm install`。
- 已存在：先确认当前分支为 `main` 且工作区干净；然后执行非破坏性的：

  ```sh
  git pull --ff-only origin main
  ```

如发现冲突、非 `main` 分支或工作区不干净，立即停止。不得使用 `git reset` 或任何会丢弃改动的命令。

## 2. 配置 Local Agent Edge

让人类执行：

```sh
npm run edge:setup
```

随后，你必须检查你自己当前实际使用的 CLI 运行环境，确定准确的非交互式命令、参数与工作目录。

绝不猜测 CLI、会话或参数。确认后，只返回给人类**一整行**可粘贴的配置文本，格式必须为：

```text
edge:configure {...}
```

配置中不得包含密码、令牌、API Key、Cookie、凭据、私钥、会话密钥或任何其他秘密。

## 3. 启动并保留 Edge

让人类执行：

```sh
npm run edge:start
```

确认终端显示 `Local Agent Edge is ready`，记录完整的 Agent Card URL，并要求人类保持该终端打开。

不得将 Local Agent Edge 暴露到公网。

## 4. 创建本次 M2E 专用 SSH 公钥

创建一个本次 M2E 专用、一次性的 ed25519 SSH 密钥对，使用新的专用文件名。

- 不得覆盖或复用任何现有 GitHub、服务器或其他 SSH 密钥。
- 私钥必须仅保留在本地，绝不得打印、发送或上传。
- 仅记录完整的 `.pub` 公钥单行内容。

## 5. 回传与等待

只向测试发起人回传以下两项：

1. 完整 Agent Card URL
2. 完整 SSH 公钥单行内容

保持 Edge 继续运行，保留临时私钥，并等待后续针对单个测试的隧道指令。

不得修改、重构或自行修复项目代码；不得添加隧道框架；不得编造服务器 IP、端口或隧道命令。

## 失败处理

任一步失败时立即停止，只回传：

- 失败的准确步骤；
- 原始错误信息。

不要让人类自行排错。
